## About This Repository

This repository contains my projects completed as part of the Oasis Infobyte Data Analytics Internship Program. These projects cover exploratory data analysis, data preprocessing, machine learning, customer analytics, and natural language processing.

## Completed Tasks

### Task 1: EDA on Retail Sales Data
- Explore retail sales data and summarize important patterns.
- Analyze sales, customer demographics, product categories, and transaction trends.
- Create visualizations to communicate findings.

### Task 2: Customer Segmentation
- Explore customer purchasing behavior.
- Prepare data for clustering and customer segmentation.
- Apply clustering techniques and evaluate the results.

### Task 3: Data Cleaning
- Identify and handle missing values and duplicates.
- Standardize data formats and correct data types.
- Examine outliers and improve data quality.

### Task 4: Sentiment Analysis
- Preprocess text data.
- Classify text as positive, negative, or neutral.
- Evaluate model performance using classification metrics.

### Task 5: House Price Prediction
- Prepare housing data for modeling.
- Build regression models to predict house prices.
- Evaluate prediction performance.

### Task 6: Wine Quality Prediction
- Explore wine-quality data.
- Prepare features and target variables.
- Build and evaluate machine learning classification models.

### Task 7: Fraud Detection
- Explore transaction data for fraud patterns.
- Address class imbalance where appropriate.
- Train and evaluate fraud detection models.

### Task 8: Google Play Store Analysis
- Analyze app information and user reviews.
- Explore app ratings, categories, and review sentiment.
- Present insights through data analysis and visualizations.

### Task 9: Autocomplete and Autocorrect
- Explore text prediction and spelling correction techniques.
- Implement autocomplete and autocorrect approaches.
- Compare their performance using suitable evaluation metrics.
